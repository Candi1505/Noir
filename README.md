# Onyx Command

Onyx Command is a mobile-first tactical companion for players who want their chest, season, rider, base and Atlas planning in one clean command centre.

## Command centres

- Chest Intelligence: live event predictors, reward search, history, drop rates, budgets and Double Armoury planning.
- Season Command: branch exploration, key routing, sigil checkpoints and saved player progress.
- Rider Command: explainable rider matching, class and mission filters, skills and gear intelligence.
- Base Command: tower catalogue, manual eight-island tactical map, monuments, perches, rider gear, estimated DP sandbox, tower merge and Fortification planning.
- Atlas Command: team overview, battle ledger, castle watch and manual command records using Atlas terminology.
- Profile: account-scoped saved command state and access controls.

## Planning principles

Onyx keeps manual geometry manual, labels calculated values as estimates and separates owner-maintained source data from player-entered command state. It does not invent a base layout, missing inventory or unverified combat effects.

The public application does not include raw private source files, credentials or account traffic. Base reference screenshots remain in the browser where they were added and are not saved to a player profile.

## Reporting a problem

Please include the screen, action, result you saw and result you expected. A screenshot is useful when the problem is visual; never include passwords, session details or private account exports.
